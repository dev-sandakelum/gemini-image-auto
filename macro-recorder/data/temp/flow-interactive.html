Poll tick ▸

every 1000ms

Count images in output-img/, read the last known count from count.txt.

This runs continuously in the background. Everything below only fires once images > count.txt.

?
images > count.txt ?
NO → idle, wait for next tick YES → start cycle
•

Write count.txt ▸

crash‑safe

New image count is written to count.txt before any macro runs.

Doing this first means a crash mid‑cycle can't cause the same image to trigger a duplicate run.

•

Clean data/queue/ ▸

Delete any leftover images from a previous run before starting fresh.

Guarantees the next "queue empty vs image found" check can't be fooled by a stale file.
